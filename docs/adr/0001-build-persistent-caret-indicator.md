# 기성 무료툴을 쓰지 않고 캐럿 상주형 표시기를 직접 만든다

윈도우용 무료 한/영 표시기(IMECursor, KorTooltip 등)는 대부분 **마우스 포인터 옆**이나 **화면 고정 위치**에만 표시하고, 텍스트 캐럿을 따라다니는 상주형은 사실상 없다(IMECursor 저자 본인도 캐럿 추종을 아쉬워함). 우리는 macOS처럼 **텍스트 캐럿 바로 옆에 항상 상주**하며 **모든 앱**에서 동작하는 표시기를 직접 만들기로 한다 — 이 특정 UX가 시장에 비어 있고, 그것이 이 프로젝트의 유일한 존재 이유이기 때문.

## Considered Options

- **마우스 포인터 옆 표시(기성 IMECursor/KorTooltip 사용)** — 오늘 당장 무료로 해결되지만, 시선이 가는 텍스트 캐럿이 아니라 마우스에 떠서 원하는 경험이 아님. 기각.
- **화면 고정 위치 표시(IMEDisplay 류)** — 캐럿 추적 불필요로 쉽지만 "커서 옆"이라는 핵심 요구와 불일치. 기각.

## Consequences

전역 캐럿 위치 추적이라는 최대 난관을 정면으로 떠안는다. 일부 앱은 캐럿 위치를 노출하지 않으므로 완전한 전(全) 앱 커버리지는 불가능하며, 캐럿을 얻지 못하는 앱에서의 폴백(fallback) 정책을 별도로 정해야 한다.

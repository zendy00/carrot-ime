# 앱을 관리자 권한으로 실행한다

관리자 권한으로 뜬 창(관리자 CMD, 일부 시스템 창)의 캐럿은 일반 권한 프로세스가 읽지 못한다. 이 앱은 그런 창에서도 캐럿을 추적하기 위해 **관리자 권한(requireAdministrator)** 으로 실행한다 — uiAccess 서명 방식(코드서명 인증서 + Program Files 설치 필요)보다 구성이 단순하고, "지원 안 함"보다 커버리지가 넓기 때문.

## Considered Options

- **일반 권한 실행** — 가장 단순·안전하나 관리자 창에서 캐럿을 못 읽음. 기각.
- **uiAccess=true 서명 매니페스트** — 일반 권한을 유지하며 관리자 창 접근이 가능하지만 코드서명 인증서와 신뢰 경로 설치가 필요해 셋업이 복잡. 기각.

## Consequences

- 매니페스트에 `requestedExecutionLevel level="requireAdministrator"` 필요 → 실행 때마다 UAC 프롬프트.
- 자동 시작은 레지스트리 Run 키로는 권한 상승이 안 되므로, **작업 스케줄러(Task Scheduler)에 "가장 높은 권한으로 실행" 작업**을 등록하는 방식으로 구현해야 한다.
- 상시 관리자 권한 상주는 보안 표면이 넓어지는 트레이드오프를 감수한 것.

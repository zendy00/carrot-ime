# 05 — 기타 IME 상태 `[あ]`/`[中]`/`[IME]`

**What to build:** 일본어·중국어 등 다른 IME로 입력할 때 그 언어를 나타내는 글자(`[あ]`/`[中]` 등)를 보여주고, 언어를 특정하지 못하면 `[IME]`로 표시한다. 결정 코어에 세 번째 입력 상태(기타 IME)와 언어별 라벨 매핑을 추가한다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 일본어 IME 입력 시 `[あ]`가 표시된다
- [ ] 중국어 IME 입력 시 `[中]`가 표시된다
- [ ] 언어를 특정 못 하는 IME는 `[IME]`로 폴백 표시된다
- [ ] 한글/영문 판별이 회귀 없이 유지된다
- [ ] 결정 코어 `Decide`의 기타 IME 상태 판별·라벨 매핑이 단위 테스트로 검증된다

## 리뷰 노트 (code-review)

- **`[IME]` 폴백이 실경로에서 도달 불가(후속 개선):** `ResolveState`가 일본어(0x11)·중국어(0x04)만 `OtherIme`로 분류하고 나머지는 `English`로 떨어뜨려서, 실제 `Decide` 경로로는 "OtherIme + 미상 언어" 조합이 나오지 않는다. 따라서 베트남어·태국어 등 다른 IME는 `기타 IME`가 아니라 `영`으로 표시된다. `Label`의 `IME` 폴백은 단위 테스트(직접 호출)로만 커버됨.
  - 근본 원인: `InputSnapshot`에 스펙이 명시한 "IME 이름/식별자" 필드가 없어, 조합 가능한 미상 IME를 라틴 레이아웃과 구분하지 못함.
  - 후속: IME 이름/조합 가능 여부를 스냅샷에 추가해 미상 IME를 `OtherIme`로 승격 → `IME` 폴백을 실경로로 연결.
- **적용:** `_lastActivityTick` 매직 0 → nullable로 변경, caret==null 시 debounce 무효(의도된 한계) 주석 추가.

# 05 — 기타 IME 상태 `[あ]`/`[中]`/`[IME]`

**What to build:** 일본어·중국어 등 다른 IME로 입력할 때 그 언어를 나타내는 글자(`[あ]`/`[中]` 등)를 보여주고, 언어를 특정하지 못하면 `[IME]`로 표시한다. 결정 코어에 세 번째 입력 상태(기타 IME)와 언어별 라벨 매핑을 추가한다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 일본어 IME 입력 시 `[あ]`가 표시된다
- [ ] 중국어 IME 입력 시 `[中]`가 표시된다
- [ ] 언어를 특정 못 하는 IME는 `[IME]`로 폴백 표시된다
- [ ] 한글/영문 판별이 회귀 없이 유지된다
- [ ] 결정 코어 `Decide`의 기타 IME 상태 판별·라벨 매핑이 단위 테스트로 검증된다

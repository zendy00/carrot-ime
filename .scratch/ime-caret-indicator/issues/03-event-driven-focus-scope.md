# 03 — 이벤트 기반 포커스+위치 감지 & 표시 범위 한정

**What to build:** 편집 가능한 텍스트에 포커스가 있을 때만 인디케이터가 뜨고, 바탕화면·버튼 등 입력할 수 없는 곳에선 숨는다. 상태 갱신은 상시 폴링이 아니라 포커스·위치 변화 이벤트 구독으로 이뤄져 유휴 시 CPU를 거의 쓰지 않는다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 텍스트 입력창에 포커스가 있을 때만 인디케이터가 보인다
- [ ] 바탕화면 클릭·버튼 포커스 등 편집 불가 상황에선 인디케이터가 사라진다
- [ ] 창을 전환하면 표시 여부가 즉시 갱신된다
- [ ] 아무 입력이 없을 때 유휴 CPU 사용이 거의 0에 수렴한다
- [ ] 결정 코어 `Decide`의 표시/숨김 규칙이 단위 테스트로 검증된다

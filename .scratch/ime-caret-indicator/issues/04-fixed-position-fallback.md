# 04 — 고정 위치 폴백 (캐럿 못 얻는 앱)

**What to build:** 편집 포커스는 있지만 어떤 방법으로도 캐럿 위치를 얻지 못하는 앱(일부 일렉트론·게임 등)에서, 인디케이터가 사라지지 않고 활성 창 우상단 고정 위치에 떠서 현재 상태를 알려준다.

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 캐럿을 못 얻는 편집 상황에서 활성 창 우상단에 인디케이터가 뜬다
- [ ] 캐럿을 얻을 수 있는 앱에서는 여전히 캐럿 옆에 뜬다(폴백이 오작동하지 않음)
- [ ] 활성 창이 바뀌면 폴백 위치도 그 창을 따라 갱신된다
- [ ] 결정 코어 `Decide`의 폴백 위치 규칙이 단위 테스트로 검증된다

## 리뷰 노트 (code-review)

- **멀티모니터 폴백:** 폴백 배지가 놓일 화면을 활성 창 **우상단** 기준으로 고르도록 수정(좌상단→우상단). 두 모니터에 걸친 창에서 배지가 엉뚱한 화면으로 클램프되는 것 완화. 실기 멀티모니터에서 최종 확인 권장.
- **적용:** InputSnapshot 생성부를 named argument로(인접한 두 Rectangle 인자 혼동 방지), OverlayForm의 중복 FillEllipse 제거(BackColor+Region으로 충분).

# 06 — 트레이 상주 + 설정 + 자동 시작

**What to build:** 프로그램이 시스템 트레이에 상주하며, 메뉴로 인디케이터 켜기/끄기(일시정지)와 종료를 할 수 있고, 부팅 시 자동 시작을 설정에서 켜고 끌 수 있다. 관리자 권한으로 실행되므로 자동 시작은 UAC 창 없이 상승 실행되도록 작업 스케줄러의 "가장 높은 권한으로 실행" 작업으로 등록한다. 설정 값은 재실행해도 유지된다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 트레이 아이콘이 뜨고 메뉴에서 프로그램을 종료할 수 있다
- [ ] 메뉴에서 인디케이터를 일시정지/재개할 수 있다
- [ ] 설정에서 자동 시작을 켜면 재부팅 시 UAC 없이 자동 실행된다
- [ ] 자동 시작을 끄면 작업 스케줄러 등록이 해제된다
- [ ] 설정 값이 프로그램 재실행 후에도 유지된다

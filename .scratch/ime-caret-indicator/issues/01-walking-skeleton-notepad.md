# 01 — 걷는 뼈대: 메모장 캐럿 옆 `[한]`/`[영]`

**What to build:** 메모장 같은 네이티브 입력창에서, 사용자가 타이핑하는 텍스트 캐럿 바로 오른쪽에 현재 한/영 상태를 나타내는 인디케이터(`[한]`/`[영]`)가 뜬다. 한/영 키로 모드를 바꾸면 라벨이 즉시 바뀌고, 캐럿이 이동하면 인디케이터가 따라온다. 인디케이터는 항상 100% 또렷하고 클릭을 통과시킨다. 이 티켓이 유일한 seam인 결정 코어 `Decide`와 첫 캐럿 어댑터·레이어드 오버레이·프로젝트 뼈대를 세운다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 메모장에서 한글 입력 중 캐럿 오른쪽에 `[한]`이 뜬다
- [ ] 한/영 키를 누르면 `[한]`↔`[영]`이 즉시 바뀐다
- [ ] 타이핑으로 캐럿이 이동하면 인디케이터가 따라온다
- [ ] 인디케이터가 방금 친 글자를 가리지 않게 오른쪽에 떨어져 뜬다
- [ ] 인디케이터를 통해 뒤의 요소를 클릭할 수 있다(클릭 통과)
- [ ] 인디케이터가 항상 100% 불투명하다
- [ ] 결정 코어 `Decide`의 한/영 판별·캐럿 옆 위치 계산이 단위 테스트(xUnit)로 평범한 값 입력에 대해 검증된다
- [ ] 관리자 권한 매니페스트로 실행되고 고DPI 화면에서 크기가 정상이다
